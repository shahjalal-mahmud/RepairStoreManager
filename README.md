# 📱 Repair Store Manager  
A modern Android application built with **Kotlin**, **Jetpack Compose**, and **Firebase** to help mobile/computer repair stores manage customers, invoices, payments, delivery dates, notifications, and printing.

---

## 🚀 Features  
- Add, edit, and manage customer repair records  
- Automated **SMS notifications** for status updates (Pending, Repaired, Delivered, Cancelled)  
- **Invoice generation** with unique, persistent invoice numbers  
- **Bluetooth POS printing** support  
- Advanced search, sort, and filtering  
- Store profile management (logo, contact info, working hours)  
- Daily delivery reminder notifications  
- Dual SIM support for SMS sending  
- Firestore real-time sync across devices  
- Clean, responsive UI using Jetpack Compose

---

## 🛠 Tech Stack  
- **Kotlin**, **Jetpack Compose**  
- **Firebase Authentication**  
- **Cloud Firestore**  
- **WorkManager**  
- **Bluetooth APIs (POS Printing)**  
- **Material 3**  

---

## 📦 Installation  
1. Clone the repository  
2. Open in Android Studio  
3. Add your Firebase `google-services.json`  
4. Sync Gradle and Run
